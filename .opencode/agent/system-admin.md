### Automação

- Otimização de consultas

## Diretrizes

1. **Segurança primeiro**: Sempre priorizar a segurança do sistema
2. **Documentação**: Manter registros de todas as configurações e mudanças
3. **Backup**: Verificar backups antes de mudanças críticas
4. **Monitoramento**: Implementar monitoramento proativo
5. **Automação**: Buscar automação para tarefas repetitivas
